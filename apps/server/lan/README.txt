升级·找朋友 局域网版
====================

在一台电脑上运行这个程序，同一个 WiFi（或同一个手机热点）下的人用手机或电脑的浏览器打开它给出的地址，
就能一起玩，不需要外网。机器人、账号、头像、各种规则和线上版一样；存档和账号存在这个文件夹的 data 里，
和线上版的账号是分开的。

一、启动

  Windows：双击 Start.bat。
    - 如果弹出「Windows 已保护你的电脑」，点「更多信息」→「仍要运行」。
    - 如果防火墙问要不要允许 node 访问网络，勾上「专用网络」后点「允许」，否则别人连不进来。

  Mac：双击 Start.command。
    - 如果提示「无法打开，因为无法验证开发者」：
      在「系统设置」→「隐私与安全性」最下面点「仍要打开」，再双击一次；
      旧一点的系统也可以按住 Control 点 Start.command，选「打开」。
    - 还是打不开：打开「终端」，输入 bash 和一个空格，把 Start.command 拖进终端窗口，按回车。

  Linux：在终端里运行 ./start.sh。

二、开始玩

  启动后会弹出一个黑色窗口，并自动在浏览器里打开游戏。玩的时候不要关这个黑色窗口，关掉服务器就停了。

  其他人：连上和这台电脑同一个 WiFi，用手机相机扫网页上的二维码，或者在浏览器里输入窗口里写的地址
  （像 http://192.168.1.23:3000 这样）。开好房间后，房间页也有二维码，扫码直接进房。

三、没有 WiFi 的时候（飞机上、山里、没信号的地方）

  局域网版不需要外网，只要大家连在同一个 WiFi 上。没有现成的 WiFi 时，可以自己开一个：

  1. 安卓手机开热点：没信号时多半也能开。飞行模式下有些手机会把热点按钮变灰，出门前先试一下。
  2. iPhone 开个人热点：没信号时多数情况下能开；开了飞行模式就不行。
  3. 随身路由器：最稳，插电或接充电宝就有 WiFi，不依赖手机。
  4. 用 Mac 自己开 WiFi（「互联网共享」）：见下面第四节。

  手机连上这种没有外网的 WiFi 时，可能提示「此 WLAN 无法访问互联网」或者自动切回移动数据，
  选「保持连接」，必要时把手机的移动数据关掉。

四、用 Mac 的「互联网共享」开 WiFi（没有路由器和热点时试试）

  Mac 可以借「互联网共享」自己开一个 WiFi，其他手机连上它就能玩。这个办法和 macOS 版本有关，
  有的电脑上开不起来，出门前请先在家试一遍：断开网线、关掉家里的 WiFi，按下面的步骤做，用手机连上后
  打开 Start.command 窗口里写的地址，能进游戏就说明可以。

  macOS 13（Ventura）及以后：
    1. 打开「系统设置」→「通用」→「共享」。
    2. 点「互联网共享」右边的 ⓘ 按钮。
    3. 「共享以下来源的连接」选「雷雳网桥」（没有就选一个没在用的接口，比如 USB 网卡）。
    4. 「使用以下端口共享给设备」里打开「Wi-Fi」。
    5. 点「Wi-Fi 选项…」：网络名称随便起（比如 shengji），安全性选「WPA2/WPA3 个人级」，
       设一个 8 位以上的密码，点「好」。
    6. 打开最上面「互联网共享」的开关，弹出确认时点「启动」，再点「完成」。
    7. 屏幕右上角的 WiFi 图标变成共享的样子，就开好了。其他人的手机在 WiFi 列表里找到刚起的名字，输入密码连上。
    8. 双击 Start.command。窗口里会列出地址（一般是 http://192.168.2.1:3000 这样），首页的二维码也会跟着变。

  macOS 12（Monterey）及更早：在「系统偏好设置」→「共享」，左边选「互联网共享」，
    其余设置和上面一样（来源选「雷雳网桥」，共享给「Wi-Fi」，在「Wi-Fi 选项」里设名称和密码），最后勾选左边的「互联网共享」。

  注意：
    - 开了共享后这台 Mac 自己就不能再连别的 WiFi 了。玩完记得回到同一个地方把「互联网共享」关掉。
    - 如果「互联网共享」开关是灰的或者开不起来，说明这台 Mac 不支持这样用，请改用手机热点或随身路由器。
    - 如果先打开了 Start.command 再开共享，窗口里没有新地址也没关系，刷新首页，二维码就会换成新地址。

五、连不上怎么办

  - 确认大家连的是同一个 WiFi。有些公共 WiFi（酒店、咖啡馆）不让设备互相访问，可以改用一部手机开热点，
    电脑和其他手机都连这个热点。
  - Windows 要在防火墙里允许 node（见上面）。
  - 地址里的 localhost 只有这台电脑自己能用，别人要用 192.168 / 10. / 172. 开头的那个地址。
