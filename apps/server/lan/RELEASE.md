没有外网时也能玩：在一台电脑上运行，同一个 WiFi（或同一个手机热点）下的人用手机浏览器扫码进来。每次更新游戏后自动重新打包。

**下载**（选这台电脑的系统）：

- Windows：`shengji-lan-windows-x64.zip`
- Mac（M1 及以后的苹果芯片）：`shengji-lan-mac-arm64.zip`
- Mac（Intel 芯片）：`shengji-lan-mac-x64.zip`
- Linux：`shengji-lan-linux-x64.zip`

**用法**：解压，Windows 双击 `Start.bat`，Mac 双击 `Start.command`，会自动在浏览器里打开游戏，首页有给别人扫的二维码。系统拦着不让打开、或者别人连不进来，看压缩包里的 `README.txt`。
